# 🌱 Cachetona · programa-para-volver

Aplicación web con **Flask**: un servidor minimalista (`app.py`) que sirve una interfaz completa (`index.html`) con registro de interacciones.

## 🧱 Estructura

```
programa-para-volver/
├── app.py        # Servidor Flask
└── index.html    # Interfaz web (HTML + CSS + JS)
```

## 🚀 Ejecución local

```bash
pip install flask
python app.py
```

La aplicación queda disponible en `http://127.0.0.1:5000`.

## 🛠️ Stack

Python · Flask · HTML · CSS · JavaScript
